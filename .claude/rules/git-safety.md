# Git and Workspace Safety

- Inspect `git status` before edits.
- Do not use `git stash` unless explicitly requested; the project report warns about untracked files.
- Do not run `git reset --hard`, `git clean`, destructive checkout, or mass deletion without explicit user approval.
- Never discard unrelated user changes.
- Do not commit, push, merge, rebase, or switch branches unless the user explicitly asks.
