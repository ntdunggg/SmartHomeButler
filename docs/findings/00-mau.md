## 1. Đang nói về phần nào

Phần nào của hệ thống, ví dụ câu nói, kết quả đúng phải là gì.

## 2. Vấn đề tìm ra

Kết quả thực tế, vị trí trong code (file:dòng), nguyên nhân gốc. Vì sao test hiện tại không bắt được.

## 3. Đã test như thế nào

Lệnh tái hiện, trạng thái ban đầu, bảng kết quả.

## 4. Hướng giải

Tham chiếu trong ngành nếu có, đề xuất sửa, test cần viết trước khi sửa (phải đỏ), quyết định cần chốt.
